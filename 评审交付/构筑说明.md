# 构筑说明

本说明把原始技能、灵兽和关系图按“目的—运转—优缺点—反制—规则风险”重新组织。它用于理解，不代表已经验证平衡。

## 多武器

**目的**：让一只或多只灵兽携带多个武技，通过高频行动、暴击和全队技能伤害成长滚雪球。

**核心内容**：蚁王、角蛙、鬼蜂、饿狼、巨鳄蚁、圣象甲虫；啃咬、利爪、双镰、乱抓、龙牙斩。

**运转链**：武技触发 → 连抓/锋锐鳞片等追加攻击 → 暴击 → 龙牙斩等提高全队武技伤害 → 下一轮更强。

**优点**：启动快、组合数量多、升级反馈直接。

**缺点与反制**：依赖多次行动和核心光环；封刃、减攻、限制暴击或优先击杀光环灵兽都可反制。

**当前风险**：高频、多重、暴击和永久/整场成长形成乘法关系，必须限制单事件触发次数和整场成长上限。

## 灼烧

**目的**：先通过点燃施加或引爆灼烧，再利用灼烧伤害触发治疗、成长或额外伤害。

**核心内容**：花椒蟹、白蔷薇、赤精鱼；引火、鞭炮、火球、妒火、火中取栗。

**运转链**：点燃 → 灼烧留存 → 被攻击时结算 → 白蔷薇治疗/花椒蟹补伤害 → 其他技能被加速。

**优点**：持续伤害和续航能够结合，构筑辨识度较高。

**缺点与反制**：依赖状态留存，怕净化、免疫及快速击杀；对触发顺序高度敏感。

**当前风险**：必须区分“攻击命中”“灼烧造成伤害”“点燃引爆”是不是同一个事件，否则不同人会得出不同结算结果。

## 剧毒

**目的**：使用淬毒施加或提前触发剧毒，在回合结束形成持续压力，并通过治疗和护盾维持生存。

**核心内容**：蕈章、沼泽鼠、黑玫瑰；毒钩、毒雾、蜈蚣锁、泰诺地龙、毒腺。

**运转链**：治疗或主动施毒 → 剧毒留存/结算 → 黑玫瑰治疗友方 → 沼泽鼠再次施毒。

**优点**：能够绕过纯护盾式防守，并自然连接治疗体系。

**缺点与反制**：启动较慢，依赖状态；净化、禁止治疗和爆发击杀有效。

**当前风险**：黑玫瑰与沼泽鼠可能互相触发。需要事件ID、直接/间接来源以及“同一效果对同一事件仅响应一次”的规则。

## 护盾

**目的**：持续获得护盾，保护输出单位，并把护盾获得事件转化为增伤或团队分发。

**核心内容**：岩豚、泥沼妖、圣象甲虫、鲛人枪手、巨伞蕈；披甲、叠甲、凝血铠甲、双盾、膨胀力场。

**运转链**：使用武技或获得增减益 → 生成护盾 → 巨伞蕈分发/鲛人枪手获得技能成长 → 提高持续作战能力。

**优点**：容错高，能够保护核心构筑件。

**缺点与反制**：贯通、破盾、持续伤害及成长速度更快的构筑可以克制。

**当前风险**：护甲与护盾混用；在未统一减伤、消耗和暴击规则前无法比较强度。

## 弹药

**目的**：用有限次数的高爆发取得开局优势，再通过装填恢复资源。

**核心内容**：铁丸子、玄铁龟；袖箭、爆破符、飞针盒、双镰、快速换弹、黄金飞梭。

**运转链**：消耗弹药 → 触发多重/暴击 → 铁丸子或换弹技能装填 → 再次爆发。

**优点**：技能顺序与装填目标可以形成明确决策。

**缺点与反制**：资源耗尽后有空窗，拖长战斗或打断装填可克制。

**当前风险**：黄金飞梭允许0弹药触发，与通用弹药规则冲突；必须明确强制使用是否消耗弹药。

## 充能

**目的**：通过小技能积累能量，在达到爆能门槛后释放范围伤害或团队增益。

**核心内容**：烁德童子、赤精鱼、玄铁龟；蓄能、吐纳术、轻击、剑气、天火咒、元气弹。

**运转链**：回合或技能充能 → 达到门槛 → 爆能消耗 → 释放高价值效果 → 重新积累。

**优点**：节奏清晰，有机会成为区别于《The Bazaar》的主要原创资源系统。

**缺点与反制**：前期较弱，怕延迟、能量干扰或快速压血。

**当前风险**：能量不足时“改为获得能量”和元气弹的“消耗后进入倒计时”没有统一状态机。

## 暴击

**目的**：提高暴击率，用暴击驱动额外使用、全队武技成长或能量收益。

**核心内容**：巨鳄蚁、见闻兽；凌厉、专注、激昂、龙牙斩、黄金飞梭。

**运转链**：友方行动 → 暴击率成长 → 暴击 → 全队武技增伤/额外使用/获得能量。

**优点**：爆发反馈强，与多武器天然兼容。

**缺点与反制**：随机波动大；降低行动次数、击杀暴击核心或加入抗暴属性都可反制。

**当前风险**：暴击定义覆盖伤害、治疗、护盾和状态层数，范围过宽，必须建立可暴击效果白名单。

## 增减益

**目的**：用亢奋放大己方成长，用衰弱削弱敌方强化，并触发其他技能成长。

**核心内容**：黑犬、蚁王；巨力、尾鞭、风刃、全力冲撞、气场。

**运转链**：施加亢奋/衰弱 → 相关技能成长或获得护盾 → 再次施加状态。

**优点**：能够连接输出、护盾、暴击等多个体系，是重要的桥梁机制。

**缺点与反制**：容易成为所有构筑都必须带的万能组件；净化、免疫或优先击杀辅助可以反制。

**当前风险**：亢奋与衰弱涉及翻倍和减半，但未定义先获得状态还是先修正本次数值。

## 推荐的三套验收阵容

后续真正验证时，不建议只看单项数字或总胜率，应固定三套完整阵容互相对战：

1. 多武器暴击：验证高频触发、暴击成长和上限。
2. 灼烧治疗：验证点燃、灼烧、治疗的事件顺序。
3. 剧毒护盾：验证持续伤害、护盾和潜在循环。

每场日志至少记录：回合/阶段、事件ID、来源、技能或物品、目标、效果、数值前后、触发原因及是否为间接触发。
