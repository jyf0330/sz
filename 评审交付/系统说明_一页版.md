# 灵兽构筑战斗系统｜一页说明

## 一句话理解

玩家把灵兽部署到有朝向和距离的棋盘上，为每只灵兽装备不同长度、类别和品质的技能，通过状态、资源与触发链形成构筑，并在自动或半自动回合战斗中击败对方。

## 四个核心对象

1. **灵兽**：拥有生命、攻击、防御、站位和被动，是技能的携带者。
2. **技能**：提供攻击、治疗、护盾、状态、资源或触发效果；分短篇、中篇、长篇及武技、术法、心法、暗器等类别。
3. **状态**：灼烧、剧毒、再生、衰弱、亢奋等，会在受击、回合结束或其他事件中结算。
4. **资源**：弹药、能量和倒计时，决定技能能否使用以及何时爆发。

## 品质与成长

- 品质顺序：青铜 → 白银 → 黄金 → 钻石。
- 原表通常只在升级行填写变化值，其余字段留空。评审阅读版为了便于阅读，会显示继承后的完整描述；这只是阅读假设，不等于制作规则已经确认。
- 当前大量生命、攻击和效果按品质近似翻倍，但尚未提供品质功率预算、获取成本或对局验证，因此不能据此判断平衡。

## 元素机制

- **点燃**是施加/引爆能力，**灼烧**是留在目标身上的状态。
- **淬毒**是施加/触发能力，**剧毒**是留在目标身上的状态。
- 这类“施加手段＋留存状态”的双层设计可以发展出净化、扩散、转移、吸收和引爆，是当前最值得强化的原创支柱之一。

## 八套主要构筑

- 多武器：依靠高频武技、暴击和技能伤害成长。
- 灼烧：叠加灼烧，通过受击或点燃引爆，再转化为伤害、治疗和成长。
- 剧毒：叠加剧毒，在回合结束或淬毒引爆时结算，并与治疗、护盾交叉。
- 护盾：持续获得护盾并转化为团队生存或技能成长。
- 弹药：有限爆发，通过装填和额外使用维持输出。
- 充能：积累能量，达到爆能门槛后释放高价值效果。
- 暴击：暴击驱动额外使用、全队成长或能量收益。
- 增减益：使用亢奋和衰弱放大己方成长、压制敌方强化。

## 一场战斗目前缺少的关键答案

1. 回合开始、移动、技能、攻击、死亡检查和回合结束的唯一顺序是什么？
2. 被动触发的效果能否继续触发另一个被动？如何阻止循环？
3. 攻击、技能伤害、防御、护盾和固定伤害的公式是什么？
4. 随机目标、最高/最低目标出现并列时怎样选？
5. 倒计时减到0是立即触发还是等待下一个阶段？
6. 护甲与护盾是不是同一资源？
7. 暴击可以放大哪些效果，哪些不能？
8. 标准阵容规模、标准战斗时长和品质功率预算是什么？

在这些问题得到统一答案前，这套材料可以用于讨论构筑，但还不能作为无歧义的程序配置或平衡结论。

## 与《The Bazaar》的关系

当前方案明显借鉴了物品品质、体积/长度、弹药、暴击、相邻位置、触发成长和构筑联动，并在原型列直接记录了多项参考对象。它不是完全照搬，因为还加入了灵兽载体、格子射程、移动、朝向、亢奋/衰弱和充能/爆能。

判断是否摆脱“换皮感”的标准不是名字和美术是否变化，而是玩家决策是否变化：触发条件、站位选择、风险成本、反制手段和构筑路径至少需要发生实质改变。

## 建议阅读顺序

1. 先看本页，理解对象和构筑。
2. 打开 `新数值_评审阅读版.xlsx` 的 `04_构筑导航`。
3. 从感兴趣的构筑进入 `01_技能总表` 和 `02_灵兽总表`。
4. 遇到疑问时查 `03_机制词典`。
5. 最后查看 `05_规则风险` 和 `06_大巴扎审计`，判断是否能制作及原创性风险。
