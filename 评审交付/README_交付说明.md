# 评审交付包

## 文件

- `新数值_评审阅读版.xlsx`：主要入口。把技能和灵兽升级行展开为便于阅读的完整记录，并增加构筑导航、规则风险和借鉴审计。
- `系统说明_一页版.md`：十分钟理解系统的最短入口。
- `构筑说明.md`：按八套构筑说明目标、运转、优缺点、反制和规则风险。
- `规则缺口清单.xlsx`：20项影响制作、测试和平衡的规则缺口。
- `大巴扎借鉴审计.xlsx`：根据原表“原型”列整理的一对一映射风险及改造建议。
- `交互关系_重绘版.svg` / `.png`：按资源层、触发层、构筑层和结果层重绘的关系图。
- `build_review_pack.py`：可重复生成三个Excel交付文件的脚本。
- `render_interaction_map.py`：可重复生成PNG关系图的脚本。

## 边界

- 原始 `新数值.xlsx` 与 `交互关系.pdf` 未修改。
- 阅读版对升级行的空白采用“继承基础行”的展示假设，并在文件中明确标注；正式配置仍需作者确认。
- 借鉴审计评价的是产品辨识度和设计映射风险，不构成法律结论。
- 本轮没有替作者修改技能数值，也没有宣称任何构筑已经平衡。

## 推荐使用方式

先读一页说明，再打开阅读版的“构筑导航”。选中一套构筑后查看对应技能和灵兽，最后根据规则风险清单向作者逐项追问。
