# 灵兽构筑 · 机制图谱 v0.2

入口：`index.html`。发送给他人时，只需发送 `交互关系_单文件分享版.html`，浏览器离线打开即可。原始 PDF 和 Excel 也嵌在分享版内。

## 本版内容

以 `新数值.xlsx` 为基础内容，并合并 `scripts/editor-patch.json` 中最新图鉴编辑结果。当前收录 108 个物品（25 个灵兽、83 个技能），其中包含编辑器新增条目和对原表条目的覆盖；青铜、白银、黄金起始都保留。

10 类机制图展示 57 条关键关系节选，每行按“条件 / 时机 → 响应物品 → 效果 / 作用对象”独立阅读。触发条件与效果文本直接取自对应基础行，点击效果卡可查看原文依据、工作表与行号。所有物品完整基础字段可从目录和悬停详情查看。

- 区分护盾、护甲和防御；区分施加、受到、获得等条件。
- 流程图不是全部规则的穷尽图，也不表示跨物品的执行顺序或已验证阵容。额外效果和限制查看完整详情。
- 名称全部采用表格原文：鲛人抢手、钩链、快速换弹、蛇影寒等，不继续沿用 PDF 中不同的命名。
- 分类依据效果、能力和词条中的相关词以及人工核对的关系条目，只作浏览索引，不推断存在额外效果。
- 原表空白不推算，原表内的含糊和未闭合规则不擅自补写。高品质数据暂不展开。

## 交互

悬停物品显示完整效果与关键数值，点击固定详情；点击效果卡查看当前关系的证据。全表搜索支持名称和效果关键词，目录可按灵兽/技能筛选。桌面是横向流程图，小屏自动切为纵向流程；支持展开、缩放、Tab/Enter、Esc 关闭与 `/` 聚焦搜索。

## 图鉴编辑器

`editor.html` 是灵宠与技能图鉴工作台。可查阅全部灵宠和技能，按青铜、白银、黄金、钻石分别编辑数值。灵宠只有被动能力；技能将主动效果与被动效果分栏编辑，能力作为主动效果前置并继续在战斗中显示。技能防御、弹药技能开关与弹药上限均可调整；未启用弹药的技能在模拟器中显示 `-/-`，主动使用不消耗弹药。编辑器还提供 9×9 攻击范围编辑器：施法者固定在中央、面朝上方；无条件技能用红格指定实际命中位置，条件技能用灰格指定候选范围；目标阵营可选敌方、友方、自身、自身与友方、自身与敌方。灵宠支持生命、攻击、防御、标签、被动效果、套路定位与升级理由。两类条目都可以复制或新建设计，效果字段支持直接输入完整规则文本。

编辑内容保存在当前浏览器的本地工作副本中，不会覆盖 `新数值.xlsx` 原件。`index.html` 和 `battle.html` 会优先读取同一份本地覆盖数据；新灵宠和新技能都可在战斗模拟器的战斗配置中选择。战斗模拟器会执行范围格、目标阵营、单/多/全体模式，以及生命、攻击、防御、前后方、点燃、剧毒、霜冻、护盾和随机数量条件。主动与被动触发技能都会按效果描述中的每个分句分别识别“目标”“自身”“目标和自身”“我方全体”“敌方全体”等作用对象。编辑器可分别导出 Excel 可打开的全量灵宠/技能 CSV（含结构化范围 JSON），以及便于备份和迁移的 JSON 编辑补丁。

主动效果和被动效果分别拥有简化效果编辑器。灵宠使用主动面板作为被动简化编辑。可多选战斗开始、回合开始、回合结束、被攻击、受到伤害、使用技能、造成伤害、失去护盾、战斗结束/胜利和弹药耗尽等时机，为单位目标、左/右相邻技能、灵兽自身技能或己方所有技能组合充能、装填弹药、位移、伤害、治疗、护盾及常用状态。爆能和倒计时可选择“额外效果”或“应用于此技能”：前者只在爆能成功或倒计时归零时执行内嵌效果，后者会门控基础能力及后续效果；同一规则中写在爆能前的充能先结算，写在爆能后的效果只在爆能成功后结算。应用后生成可读的 `【触发时机】对象：效果。` 规则行，只替换同格式规则并保留其它手写内容；战斗模拟器始终重新读取最终效果文本。

## 更新

1. 修改原表或图鉴编辑补丁后，用 Python（需要 `openpyxl`）运行 `scripts/build.py`，生成 `graph-data.js` 并校验 `scripts/rules.json` 的原文片段。
2. `scripts/rules.json` 存放机制与人工核对的关系节选；每个条件与效果必须存在于所指物品的最低品质效果原文中。
3. 修改样式与交互使用 `styles.css`、`app.js`。
4. 运行 `python3 scripts/build_standalone.py` 重新生成分享版。

## 预摆小循环示例

默认入口新增三套讲解组合，每套一只核心灵兽和两件技能，卡片支持悬停完整数据、组合分工以及点击固定。

1. 自毒换盾：鲛人抢手 + 蜈蚣锁 + 蜷缩。自身获得剧毒，转换为护盾/再生，再响应为随机自身技能伤害成长。
2. 能量回充：玄铁龟 + 蓄能 + 袖箭。积累能量，在回合开始满足消耗6能量条件后补弹，再继续积累。
3. 暴击养武技：巨鳄蚁 + 冲刺拳 + 龙牙斩。首次必暴启动武技成长，后续符合条件的暴击重复成长。

每套有四步导览、高亮和原文证据。它们是根据原表整理的局部配合示例，不是战斗模拟或已经验证槽位合法性的正式阵容。卡片位置不代替正式站位，随机加伤、再循环所需的新动作、能量门槛及非必暴条件均单独说明。

配置在 `scripts/examples.json`；构建时校验物品存在、步骤引用原文及高亮物品。`scripts/verify_examples.cjs` 验证三套切换、四步高亮、悬停、手机、页面切换和单文件离线使用，结果见 `verification/examples-results.json`。

## 完整配队范例

`scripts/team-presets.json` 收录《配队范例.docx》的三套四灵宠编队：暴击成长、快速输出、火热能量。图谱首页会展示每只灵宠的品质与装备技能；进入 `battle.html` 的“战斗配置”后，可以把任一范例一键载入己方或对手。图谱中的“去编队界面载入”链接会直接打开并预载对应范例。三套范例的英雄生命均为 660，技能总格数均为 10。队伍3的“预先充能”按图鉴编辑器中的实际名称 `预充能` 载入，黄金品质技能为 `乱抓`。

文档中的“蓄力”和“飞爪钩”分别对应当前图鉴里的“蓄能”和“飞抓钩”，图谱保留文档称呼并提示图鉴名，实际模拟使用图鉴名。`scripts/verify_presets.cjs` 覆盖图谱展示、编队载入、品质、别名、技能格数与移动端布局。

## 品质标签同步

技能与灵宠的标签统一由起步品质维护。构建数据时，各品质阶段会写入同一份起步品质标签；图鉴编辑器仅允许在起步品质页签修改标签，保存后会同步到所有品质阶段。已有浏览器本地补丁在读取、导入或再次保存时也会自动归一。

## 战斗页新手引导

战场顶部会根据部署、己方结算、敌方结算和战斗结束状态，实时告诉玩家当前可执行的操作。点击战场灵宠、技能卡、商店或背包物品可直接打开完整详情；页面内带 `ⓘ` 的战斗术语可打开速查说明。“新手指引·术语”集中列出首局步骤及当前沙盒的战斗资源、状态和结算规则。
